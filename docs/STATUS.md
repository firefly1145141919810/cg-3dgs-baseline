# 当前交付与验证范围

本文件只描述当前状态，历史开发进度保留在Git历史。研究过程与结果见[实验文档](COMPRESSION_EXPERIMENT.md)，运行方法见[README](../README.md)。

## 已完成的实验证据

- train、truck两场景官方30k baseline；100%保存重载正确性检查。
- 不透明度与训练视角贡献度剪枝，固定数量3k恢复和同预算完整恢复对照。
- 两场景70%/50%/30%，共36组最终质量记录、18组恢复训练记录。
- 18个恢复后模型设置各3个独立进程计时，共54份样本；全部来自同主机同作业，最大相对耗时范围0.536%。
- 统一审计复算全测试视角均值、训练记录、210张图片哈希、180张渲染像素PSNR及计时统计。
- 22页技术报告、7张实验图、6张数据表；结论保留负结果、失败案例及测量限制。

## 代码与公开版本检查

检查了baseline调用、参数保存重载、稳定选点、颜色梯度评分、恢复学习率与数量约束、六组对照和计时统计。当前54项CPU测试及36个Python文件静态解析通过；新增公开发布工具测试覆盖脱敏、原始文件不变、哈希映射、拒绝覆盖/路径越界和扫描规则。不把静态检查当作GPU验证。

公开仓库使用HTTPS克隆。个人Slurm脚本已取消Git跟踪并保留本地副本；作业脚本、私钥常见文件名、原始计时目录和private目录已忽略。计时公开副本隐去账号路径与节点名，附原始/公开哈希对应，统计数值不变。发布前的启发式检查入口为 `scripts/check_public_repo.py`，说明见[同步文档](SYNC.md)。

公开main历史已按授权清理Slurm、个人云端路径和节点信息，实验数值/图像保留，逐提交核验和迁移方式见[历史迁移说明](HISTORY_MIGRATION.md)。旧本地备份、fork、他人克隆和托管方缓存不等于公开main可达历史，未声称已撤回这些副本或证明不存在任何秘密。
